# Power BI Personal Projects

A collection of Power BI dashboards I've built to practice data modeling, DAX, and dashboard design using real and self-collected datasets. Each project folder includes the source `.pbix` file and a README with details on the approach and skills used.

## Projects

- **[Instagram Follow Analysis](./Instagram_Follow_Analysis)** — Analyzes Instagram follower/following data to identify non-reciprocal relationships and calculate engagement metrics, using Power Query (JSON parsing, anti-joins) and DAX (calculated measures and columns).
