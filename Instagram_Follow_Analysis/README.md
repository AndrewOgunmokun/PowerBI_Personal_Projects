# Instagram Follow Analysis (Power BI)

A Power BI dashboard that analyzes Instagram follower/following data to identify non-reciprocal relationships and calculate engagement metrics

What it does:

Imports and cleans raw Instagram data export (JSON) using Power Query, including flattening nested list structures and converting Unix timestamps to readable dates
  
Merges following and follower lists via an anti-join to classify each account as "Following Back" or "Not Following Back"
  
Calculates key metrics using DA measures: total following, total followers, follow-back rate, and count of non-reciprocal accounts
  
Visualizes the breakdown with summary cards, a donut chart, a following-vs-followers comparison, and a filterable detail table


Skills demonstrated: 

Power Query (JSON parsing, table merges, anti-joins, custom columns), DAX (calculated measures and columns), data modeling, dashboard design
